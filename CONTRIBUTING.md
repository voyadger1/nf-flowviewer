# Contributing to FlowViewer

You can contribute to the development of the project. Contributions include not only writing code and adding tests but also reporting bugs. You can also share your experience using FlowViewer; if the project doesn't handle your specific use cases well, we can work together to identify the issues and improve the product.

## Writing Code

You can create new branches to fix bugs or implement new features. Since the project consists of both a plugin and a webview component, if you need to submit a pull request for both, please include a link to the webview pull request in the comments of the other pull request.

## Reporting Bugs

Bug reports significantly help improve the product, as it is difficult for me to analyze every possible scenario on my own. You can report bugs via email or Telegram. Please provide detailed steps to reproduce the issue and, if possible, attach a screenshot. (If you are concerned about data privacy, you can create a new pipeline that reproduces the error without using your actual data.)

## Feedback and Collaboration

I am open to collaboration proposals from laboratories. If you represent a laboratory, please feel free to contact me to discuss your specific workflows. We can also arrange a call to discuss this further.
